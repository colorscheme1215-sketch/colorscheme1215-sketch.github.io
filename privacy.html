プライバシーポリシー / Privacy Policy

制定日：2026年10月27日

「栄養管理（Nutrition Manager）」（以下「本アプリ」）は、開発者本人のみが個人的に利用するツールです。第三者へのサービス提供は行っていません。

This app is a personal tool used solely by its developer. It is not offered to any third party.

1. 取得するデータ / Data accessed

  • Google Health API：睡眠、心拍・HRV、歩数・消費カロリー、体重・身長、食事記録などの健康データ
  • Google ドライブ：本人が指定フォルダに保存した食事写真
  • Google スプレッドシート：本人の記録用シート

2. 利用目的 / Purpose

本人の栄養管理とパフォーマンス向上のため、食事内容の推定、健康データとの組み合わせ分析、本人宛てのアドバイス送信、Google Health への食事記録の書き込みにのみ利用します。

3. 保存と第三者提供 / Storage and sharing

  • データは本人の Google アカウント内（Google ドライブ・スプレッドシート・Google Health）にのみ保存します。
  • 食事写真と関連データは、栄養推定のために Google の Gemini API に送信します。それ以外の第三者にデータを提供・販売することはありません。
  • Google API から取得したデータの利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

4. 削除 / Deletion

本人は、Google アカウントの「サードパーティ製のアプリとサービス」から本アプリのアクセス権をいつでも取り消せます。保存データは本人のドライブ上のファイルを削除することで消去されます。

5. 改定 / Changes

本ポリシーを改定する場合は、このページを更新します。
